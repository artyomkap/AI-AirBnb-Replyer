# Airbnb Auto-Reply Bot

This project is an intelligent automation system for Airbnb hosts, designed to automatically read guest messages and send replies via OpenAI, while maintaining human-like browser behavior to avoid detection.

---

## 🧩 Overview

The system consists of the following core components:

- **Chrome Extension**: Collects all cookies from Airbnb, including `HttpOnly`, using `chrome.debugger` API and sends them to the backend.
- **FastAPI Backend**: Receives cookies, saves them, and starts the message parsing process.
- **Playwright Automation**: Logs into Airbnb using the received cookies, checks new messages, and gathers detailed chat information.
- **OpenAI Integration** *(optional)*: Generates intelligent responses based on chat context.
- **Telegram Bot**: Provides a control panel for the admin to start/stop the bot and receive alerts.

---

## ⚙️ Features

- ✅ Secure authentication via cookies (no need to enter passwords).
- 🤖 Automatic detection of unread messages.
- 🧠 Optional smart replies generated by OpenAI.
- 🧑‍💻 Human-like behavior: delays, randomized timing, natural page interaction.
- 📬 Real-time notifications and control via Telegram.
- 🗂 Log saving and chat metadata storage.

---

## 🚀 How It Works

1. **User logs in manually to airbnb.com**.
2. **Chrome Extension** collects all cookies and sends them to the FastAPI endpoint.
3. FastAPI saves cookies and triggers the `scheduler()`.
4. **Playwright** launches a session with cookies and navigates to the Airbnb inbox.
5. Unread messages are parsed using human-like behavior.
6. (Optional) Each message is sent to OpenAI to generate a reply.
7. The system sends the reply and logs the conversation.
8. All actions and errors are reported via the **Telegram Bot**.

## 🧪 Setup & Development

### Prerequisites
- Python 3.11+
- Node.js (for Chrome Extension build/test)
- Ngrok (optional)

### 1. Run the backend
```bash
python main.py
```
### 2. Install NGROK Tunnel
- login to `https://ngrok.com`
- download oficial software
- create ngrok tunnel using command from the website
- insert ngrok address into the `popup.js` inside the `extension`

### 3. Install Chrome Extension
- Load `extension/` folder via `chrome://extensions/`
- Enable Developer Mode
- Click "Load unpacked"

### 4. Log in to Airbnb manually
- Navigate to `https://www.airbnb.com`
- Use the extension to send cookies

### 5. Control the bot via Telegram
- Start/Stop the auto-reply process
- Get live feedback

## 📌 Notes

- The bot is optimized for stability and anti-detection.
- All browser actions are delayed with random pauses to simulate human behavior.
- Ensure cookies remain valid; re-authentication may be required periodically.
